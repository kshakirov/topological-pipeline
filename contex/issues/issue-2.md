## 1. Назначение и контекст задачи
Разработать, локализовать и запустить минимальный жизнеспособный прототип топологического конвейера (MVP) в рамках единого пакета `main` для проверки физики асинхронного прохождения квантов данных.

## 2. Критерии приемки (Definition of Done)
- [x] Реализовать активную асинхронную Push-модель передачи данных между узлами.
- [x] Инкапсулировать Go-каналы внутри структуры единого провода `LocalWire`, оторвав `ComputeNode` от прямого владения шинами.
- [x] Реализовать двухтактный монолитный цикл обработки (`InBoxFunc` -> `OutBoxFunc`) внутри горутины провода.
- [x] Ликвидировать сегфолты (`nil pointer dereference`) и дедлоки на фазе инициализации портов ввода-вывода (`main.go`, `source_node.go`).
- [x] Замкнуть магистрали чтения и записи на единый физический буфер в `LocalWire` для зачистки заторов.
- [x] Подтвердить сквозной проход сообщений от `SourceNode` до выхлопа по логам рантайма.

## 3. Фиксация выполнения
Контур стабилизирован. Макет на `BoxFunc` выдает штатные такты обработки без утечек памяти и блокировок. Задача решена, инфраструктурный скелет готов к переходу на интерфейсные колбэки.
