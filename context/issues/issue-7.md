# #7 — Epic: DATA Protocol & Distributed Acknowledgement

State: open
URL: https://github.com/kshakirov/topological-pipeline/issues/7

## Цель

Построить расширяемый протокол обмена данными между узлами Go через BEAM с отслеживанием завершения всей причинной цепочки сообщений.

## Архитектура

- Go — обработка данных и порождение сообщений.
- BEAM — маршрутизация и координация подтверждений.
- Prolog — логическая топология, вне DATA hot path.

## DATA v1

Общий кадр: Magic "ST":2 | Length:uint16 BE | Opcode:uint8 | Body. Length включает Opcode + Body.

Opcode 0x04. Body:

```text
Version   uint8 = 1
Flags     uint8
RootID    uint64 BE
MessageID uint64 BE
ParentID  uint64 BE
Payload   bytes
```

Для корневого сообщения ParentID = 0. Минимальный Length = 27. Новую сериализацию Payload не вводим; существующие Opcode 01–04 сохраняем.

## Критерий завершения

Одно исходное сообщение порождает произвольное конечное дерево сообщений. Все узлы обрабатывают данные независимо. Генератор получает глобальный ACK только после завершения всех потомков. Учёт ведётся по экземплярам сообщений, а не по количеству узлов.

Формат DATA v1 фиксируем в рамках эпика. Математический алгоритм глобального ACK — отдельная задача; XOR или счётчики пока не выбираем.
